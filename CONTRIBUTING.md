# Contributing

Open an issue describing the behavior or learning goal, or submit a focused pull request. Preserve the existing compact interface, keyboard access, light/dark themes and narrow layouts. Keep formulas and provenance inspectable. Use actual computations for inference claims; label recorded results and schematics accurately.

Run `pnpm check`. For runtime changes also run the Python unit tests in the README and exercise the affected real-model path. Include the settings, observed result and any unverified branch in the pull request. Do not commit model caches, environments, private data, secrets or personal development logs.

Contributions to original code are under MIT. Preserve third-party notices and do not relicense external assets. Configure Git with a GitHub noreply email if you do not want a personal address in commit history.
